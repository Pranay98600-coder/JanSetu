# JanSetu Architecture

## Project
JanSetu - Smart Civic Issue Reporting
and Resolution Platform.

## Architecture
Modular Monolithic Architecture.

## Backend
- Java 21
- Spring Boot 4.1.2
- Spring Data JPA
- Spring Security
- MySQL

## Frontend
- React
- Vite
- Axios
- Material UI

## Database
MySQL: jansetu_db

## Communication
React communicates with Spring Boot
through REST APIs using JSON.

## Backend Port
8080

## Frontend Port
5173
